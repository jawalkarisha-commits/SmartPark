SmartPark portal

This old development console is retired. It sent protected API requests without a sign-in token, which caused the unrelated “Authentication is required” message. Use the supported portal for registration, sign-in, and parking operations.

Customer and parking-owner registration are available in the portal. Administrator accounts must be provisioned by the application operator; public registration cannot create administrators.

Open SmartPark For local development, start the application using the instructions in HELP.md.
